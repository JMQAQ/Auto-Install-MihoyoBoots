# Auto-Install-MihoyoBoots
# 全自动偷偷安装米哈游启动器

## 宇宙级安全声明
此项目为一个初学者开发，代码质量差，轻喷

## 注意事项
### 仅支持MSVC编译器
### 注意：获取UAC是为了给米哈游启动器的安装程序启动

## 程序流程
使用win32，下载准备安装原神的米哈游安装器，然后禁用输入，模拟点击确认用户协议和执行安装，模拟点击过后，恢复输入
